# To-Do App

A simple To-Do application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks from the list.
- Responsive UI for better user experience.
- Data persistence using local storage.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open the `index.html` file in your browser.
2. Type a task in the input field and click the 'Add' button.
3. Click on a task to mark it as completed.
4. Click the delete button to remove a task from the list.
5. Tasks remain saved in local storage even after refreshing the page.

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/todo-app.git
   ```
2. Navigate to the project folder:
   ```bash
   cd todo-app
   ```
3. Open `index.html` in your browser.
